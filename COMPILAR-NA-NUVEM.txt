GERAR O APK NA NUVEM (GITHUB ACTIONS)

Este projeto inclui o fluxo .github/workflows/android-apk.yml, que compila o APK em um runner Ubuntu do GitHub.

PASSOS:
1. Crie uma conta no GitHub (se ainda não tiver) e um repositório vazio.
2. Envie TODO o conteúdo da pasta comanda-facil para esse repositório, mantendo a pasta .github.
3. No GitHub, abra a aba Actions.
4. Escolha "Gerar APK Android" e clique em "Run workflow".
5. Aguarde o trabalho terminar com status verde.
6. Abra a execução concluída e baixe o artefato "comanda-facil-apk-debug".
7. Dentro do ZIP do artefato estará o arquivo app-debug.apk.

OBSERVAÇÕES:
- O APK gerado é de depuração (debug), adequado para instalação e testes internos.
- O GitHub compila o código; este projeto não envia dados do restaurante para o GitHub durante a execução do aplicativo.
- Para publicar na Play Store, será necessário gerar uma versão release assinada com uma chave privada, que deve ser mantida em segredo.
- O celular continua precisando alcançar o computador servidor pela rede Wi-Fi local.
